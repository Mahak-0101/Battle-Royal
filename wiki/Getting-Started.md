# 🚀 Getting Started

## 1) Install Engine

Install **Godot** (latest stable recommended).

## 2) Open Project

1. Clone this repository.
2. Open Godot and click **Import**.
3. Select `project.godot`.
4. Run `Main.tscn`.

## 3) Controls

- `W / A / S / D` → Move
- `Mouse` → Look
- `Left Click` → Shoot
- `Shift` → Run

## 4) Troubleshooting

- If scenes fail to load, ensure you opened the correct project root.
- If controls feel wrong, review the input map in project settings.
